# 铁路配线图绘制器

浅色桌面工具（PySide6 / Qt Widgets），用于绘制车站配线示意图：股道线段、道岔、站台、车挡、区间标记与文字标注。
支持自由绘制 + 吸附对位、撤销/重做、工程文件（`.rld`）保存与自动恢复、导出矢量 PDF。

## 运行

```bash
pip install -r requirements.txt
python main.py
```

要求 Python 3.10+ 与 PySide6 6.6+。

## 快速上手

1. 欢迎页点「新建工程」，填写图名、网格间距与纸张（默认 A3 横向）。
2. 左侧「绘制工具」按分组织，选择工具后即可绘制：
   - **股道线段（L）**：按下拖拽一次成型；或点击起点→点击终点连续画线（Esc/右键结束）。
   - **道岔**：分「单开 / 双开 / 三开 / 单式交分 / 复式交分」五种（`T` 为单开），都是两步放置——第一次点击定主线位置（点中股道会吸附到中线并把道岔居中，靠近端口会自动对位），第二次拖动定出曲股方向（光标靠股道/端口时直接对齐，否则按角度步长吸附）；右键/`Esc` 退回上一步。
   - **组合配线**：「单渡线 / 交叉渡线 / 存车线 / 折返线」自动成组绘制——依次点两条平行的股道 → 移动鼠标预览（沿股道方向定位置，越过中线可翻转生成方向）→ 再点一次生成。生成的道岔/线段/车挡都是普通图元（可单独选中、拖动、吸附），整组算一次撤销。
     - 单渡线：两条股道间一条 45° 斜线（两个道岔对顶）；
     - 交叉渡线：四个道岔 + 两条斜线在正中交叉；
     - 存车线：两条股道正中生成一条新线，两端各与上下股道相接；
     - 折返线：正中两条新线，两端接回相邻股道，两线之间再加一组交叉渡线，近端车挡收尾。
   - **站台（P）**：拖出矩形范围；**车挡（B）**：点放在股道末端；**区间标记（M）**：沿方向拖出长度；**文字（X）**：点击放置。
3. 用「选择（V）」点选元素，拖动移动；选中后出现手柄：线段两端、站台/区间的长度与宽度手柄。
4. 右侧属性面板：选中元素时改它的属性；未选中时改工程设置（图名、网格、纸张、自动恢复间隔）。勾掉股道的「正线」即按站线样式绘制。
5. `Ctrl+S` 保存 `.rld` 工程；`Ctrl+P` 导出 PDF。

## 默认样式（正线 / 站线）

「文件 ▸ 默认样式…」（`Ctrl+,`）里统一设置，改完点「保存」写入应用设置（跨会话保留）：

- **区分正线 / 站线**：打开后，股道的「正线」勾选生效（勾掉即按站线线宽颜色绘制）；
  单渡线/交叉渡线/存车线/折返线自动生成的渡线、新线与曲股也按**站线样式变细**，
  并在接轨处按「过渡长度」从正线线宽**平滑渐变**到站线线宽（正是示例图里“中间细线”的效果）。
- **正线 / 站线的线宽与颜色**、**过渡长度**（单位）、**车站（站台）填充/描边/文字颜色**。
- 设置只影响之后新建的元素与自动生成的组合；想立刻套到**图纸里已有的元素**上，点「应用到当前图纸」——
  股道按自身「正线」标记取线型、道岔更新曲股过渡、站台更新三种颜色，整批算一次撤销（`Ctrl+Z` 可退）。
- 关掉「区分正线」时全部同粗，与早期版本行为一致。

## 吸附规则

绘制/拖动时的吸附优先级：**端点与道岔端口（约 12 px）> 角度吸附 > 网格吸附**。

- 角度吸附步长在控制行选择（自由 / 15° / 30° / 45° / 90°，默认 15°），长度按网格取整。
- 从端口起笔时，角度以该端口的出射方向为基准，便于顺直续轨。
- 按住 `Shift` 临时脱离角度吸附；吸附命中时画布上出现主色小方框标记。
- 道岔第二步：光标下的股道方向会成为曲股方向（靠近端口则对齐端口朝向），否则按角度步长吸附。

## 工程文件（.rld）

JSON 明文，便于查看与版本管理；写入采用「临时文件 + 替换」保证原子性。

```json
{
  "format": "rail-layout",
  "version": 1,
  "document": { "title": "示例站", "station": "", "grid_size": 10.0, "angle_step": 15.0, "paper": { "size_key": "A3", "landscape": true } },
  "elements": [ { "type": "segment", "id": "a1b2c3d4", "x": 0, "y": 0, "rotation": 0, "length": 80 } ]
}
```

`elements[].type` 取值：`segment`、`turnout`、`platform`、`buffer_stop`、`section_marker`、`text`。
版本高于程序支持时会给出提示而不是静默打开。

## 自动恢复

- 有未保存改动时，程序每 60 秒（可在属性面板调整，最短 15 秒）把快照写入
  `%TEMP%\RailLayout\autosave\<会话>.autosave.rld`，并在同目录维护 `recovery.json` 索引。
- 保存成功或正常退出后，当前会话快照会被清理。
- 若上次是异常退出（崩溃/强杀），启动时会询问「恢复工程 / 丢弃快照」；丢弃需要二次确认。
- 原文件比快照更新时不会提示恢复（视为旧快照）。

## 单位与纸张

- 画布单位：1 单位 = 96dpi 像素 ≈ 0.2646 mm；A3 横向参考框为 1587×1123 单位。
- 纸张边框参考线只作参考（虚线绘于内容下方），导出 PDF 时不打印。
- 导出为矢量 PDF（300 dpi 设备精度），可选「整张图 / 当前视图」、A4/A3/A2/自定义、边距、以及
  「自动适配纸张」或「100% 原始尺寸」。导出时会自动隐藏网格、纸张参考线与选中状态。

## 已知限制（v1）

- 图元之间不做拓扑联动：拖动道岔不会自动带动相连线段（可用框选多选后整体拖动，再吸附微调）。
- 单文档单窗口；不支持一次打开多个工程。
- 不含信号机、绝缘节、水鹤等符号（可通过「文字标注」临时替代）。
- PDF 为单页输出；超出纸张时按设定裁切或缩放到适配。
