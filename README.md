# 铁路配线图绘制器

浅色桌面工具（PySide6 / Qt Widgets），用于绘制车站配线示意图：股道线段、道岔、站台、车挡、区间标记与文字标注。
支持自由绘制 + 吸附对位、撤销/重做、多工程标签页、绘制指引、工程文件（`.rld`）保存与自动恢复、导出矢量 PDF。

## 运行

```bash
pip install -r requirements.txt
python main.py
```

要求 Python 3.10+ 与 PySide6 6.6+。

## 多工程标签页

- 「新建工程」与「打开工程」都在**新标签页**里打开，不会顶掉正在编辑的工程；标签可拖动排序、点 `×` 或 `Ctrl+W` 关闭。
- 标签标题跟着图名走，有未保存改动时带 `*`；窗口标题始终是当前标签页的工程。
- 关闭标签页/退出程序时，只有**该页有未保存改动**才会询问「保存 / 不保存 / 取消」。
- 每个标签页各自维护撤销栈与自动恢复快照，互不干扰；崩溃后启动会逐份询问是否恢复。
- 当前页若是「未保存 + 没画任何东西 + 未改动」的空白工程，新建/打开会直接复用它，避免堆一片空标签。
- 再次打开**已在标签页中**的工程文件时直接切回那一页，避免同一文件被两份编辑互相覆盖。
- 全部标签页关掉后回到欢迎页。

## 快速上手

1. 欢迎页点「新建工程」，填写图名、网格间距与纸张（默认 A3 横向）。
2. 左侧「绘制工具」按分组织，选择工具后即可绘制：
   - **股道线段（L）**：按下拖拽一次成型；或点击起点→点击终点连续画线（Esc/右键结束）。
   - **道岔**：分「单开 / 双开 / 三开 / 单式交分 / 复式交分」五种（`T` 为单开），都是两步放置——第一次点击定主线位置（点中股道会吸附到中线并把道岔居中，靠近端口会自动对位），第二次拖动定出曲股方向（光标靠股道/端口时直接对齐，否则按角度步长吸附）；右键/`Esc` 退回上一步。
   - **组合配线**：「单渡线 / 交叉渡线 / 存车线 / 折返线」自动成组绘制——依次点两条平行的股道 → 移动鼠标预览（沿股道方向定位置，越过中线可翻转生成方向）→ 再点一次生成。生成的道岔/线段/车挡都是普通图元（可单独选中、拖动、吸附），整组算一次撤销。
     - 单渡线：两条股道间一条 45° 斜线（两个道岔对顶）；
     - 交叉渡线：四个道岔 + 两条斜线在正中交叉；
     - 存车线：两条股道正中生成一条新线，两端各与上下股道相接；
     - 折返线：正中两条新线，两端接回相邻股道，两线之间再加一组交叉渡线，近端车挡收尾。
   - **岛式站台**：依次点两条平行股道 → 移动鼠标定位置 → 再点一次，在两条股道正中生成站台，两侧自动按**默认间隔**留白。
   - **联络线（直线 / 曲线）**：依次点两条**交叉**的股道 → 移动鼠标，两个接点分别沿各自股道滑动 → 再点一次生成；曲线型是顺向弯过去的缓和曲线，不会和股道拧在一起。
   - **站台（P）**：拖出矩形范围；**车挡（B）**：点放在股道末端；**区间标记（M）**：沿方向拖出长度；**文字（X）**：点击放置。
3. 用「选择（V）」点选元素，拖动移动；选中后出现手柄：线段两端、站台/区间的长度与宽度手柄。
4. 右侧上方「绘制指引」：显示当前动作的步骤提示、光标锚定到的既有元素，以及**其余元素清单**（它们只作参照、不会被本次绘制移动；点一行即可选中并居中定位）。
5. 右侧下方属性面板：选中元素时改它的属性；未选中时改工程设置（图名、网格、纸张、自动恢复间隔）。勾掉股道的「正线」即按站线样式绘制。
6. `Ctrl+S` 保存 `.rld` 工程；`Ctrl+P` 导出 PDF；`Ctrl+W` 关闭当前标签页。

## 默认样式（正线 / 站线）

「文件 ▸ 默认样式…」（`Ctrl+,`）里统一设置，改完点「保存」写入应用设置（跨会话保留）：

- **区分正线 / 站线**：打开后，股道的「正线」勾选生效（勾掉即按站线线宽颜色绘制）；
  单渡线/交叉渡线/存车线/折返线自动生成的渡线、新线与曲股也按**站线样式变细**，
  并在接轨处按「过渡长度」从正线线宽**平滑渐变**到站线线宽（正是示例图里“中间细线”的效果）。
- **正线 / 站线的线宽与颜色**、**过渡长度**（单位）、**车站（站台）填充/副色/描边/文字颜色**。
- **新绘制的股道在交叉处断开**：打开后新画的股道在被其它股道跨越处留出缺口（每侧约 1.4 倍线宽，
  与示例图一致）；也可在属性面板里对单条股道勾选「交叉处断开」。断开只影响**显示与导出**，
  命中/吸附仍按整条线算，线段的端点、长度不变。
- 设置只影响之后新建的元素与自动生成的组合；想立刻套到**图纸里已有的元素**上，点「应用到当前图纸」——
  股道按自身「正线」标记取线型、道岔更新曲股过渡、站台更新三种颜色、联络线更新线宽颜色，整批算一次撤销（`Ctrl+Z` 可退）。
- 关掉「区分正线」时全部同粗，与早期版本行为一致。

## 吸附规则

绘制/拖动时的吸附优先级：**端点与道岔端口（约 12 px）> 角度吸附 > 网格吸附**。

- 角度吸附步长在控制行选择（自由 / 15° / 30° / 45° / 90°，默认 15°），长度按网格取整。
- 从端口起笔时，角度以该端口的出射方向为基准，便于顺直续轨。
- 按住 `Shift` 临时脱离角度吸附；吸附命中时画布上出现主色小方框标记。
- 道岔第二步：光标下的股道方向会成为曲股方向（靠近端口则对齐端口朝向），否则按角度步长吸附。
- 站台长边：与股道接近平行（夹角 ≤12°）时，长边会吸附到**默认间隔**，见下节。

## 站台与股道的默认间隔

- 默认间隔取 `examples/example5带站前单渡线的岛式站台.png` 的实测比例：站台边缘到股道中心线
  ≈ **1.4 倍股道线宽**（该图实测 13.25 px ÷ 9.5 px）；按默认股道线宽 4 单位换算就是 **5.6 单位**。
- 「岛式站台」工具按此间隔生成：站台宽度 = 两条股道中心线间距 − 2 × 间隔，并且居中；间距太窄放不下时不生成。
- 拖出或拖动站台时两条长边会自动吸附到这个间隔：只有一条边命中就整条平移，两条边都命中就居中并改宽，
  一次拖动只记一步撤销（`Ctrl+Z` 可退）。
- 正线画得很粗时，间隔会自动放大到「半个线宽 + 1.5 单位」，保证站台边线和股道不叠在一起。
- 常量与「岛式站台」尺寸都在 `core/platform.py`（`PLATFORM_TRACK_GAP_RATIO`、`gap_for_track`、`island_metrics`），
  集中一处便于按图纸微调。

## 联络线

把两条**交叉**的股道连起来（`examples/example6联络线.png`）：

- 分「联络线（直线）」与「联络线（曲线）」；曲线型用三次贝塞尔顺向过渡，两端切向沿各自股道，
  不会出现折角，也不会和股道粘成一片。
- 依次点两条交叉股道 → 移动鼠标，两个接点分别沿各自股道滑动（接点先吸附端口/网格）→ 再点一次生成。
  夹角过小（<10°）或两个接点几乎重合（<2 单位）时不会生成，避免画出退化图形。
- 联络线是独立图元：可单独选中、拖动、改类型/弦长/弯曲程度/两端切向，整条算一次撤销。
- 生成联络线**不改动**原有股道；被跨越的股道要不要断开，由默认样式里的「新绘制的股道在交叉处断开」
  或单条股道的「交叉处断开」决定。

## 站台填充（单色 / 双色 / 渐变）

选中站台后在右侧属性面板改「填充方式」：

- **单色**：只铺主色，与早期版本行为一致；
- **双色**：站台对半分，两半各一色；「分色方向」可选**沿宽度**（两条长边各一色）或**沿长度**（两端各一色）；
- **渐变**：主色平滑过渡到副色，方向同样由「分色方向」决定。

主色沿用默认样式里的「车站填充色」，副色是新增的「车站副色」（默认 `#ffcdd2`），也能在属性面板里单条覆盖。

## 绘制指引（右侧面板）

绘制/移动过程中，右侧上方「绘制指引」实时给出三件事：

- **步骤提示**：当前动作进行到第几步、下一步该做什么（例如「第 2 步：点击定终点；Shift 临时脱离角度吸附」）；
- **当前锚定**：光标吸附到的既有元素与它的端口（如「◆ 当前锚定：股道线段 #a1b2c3d4（端口：终端）」），
  即新元素正贴合在哪个元素上；
- **其余元素**：图纸里其它元素的清单——它们**固定不动**，只作参照；点某一行即可选中它并把视图居中（不会移动它）。

右键/`Esc` 退回上一步时，步骤提示与锚定信息会同步复原。

## 工程文件（.rld）

JSON 明文，便于查看与版本管理；写入采用「临时文件 + 替换」保证原子性。

```json
{
  "format": "rail-layout",
  "version": 1,
  "document": { "title": "示例站", "station": "", "grid_size": 10.0, "angle_step": 15.0, "paper": { "size_key": "A3", "landscape": true } },
  "elements": [ { "type": "segment", "id": "a1b2c3d4", "x": 0, "y": 0, "rotation": 0, "length": 80 } ]
}
```

`elements[].type` 取值：`segment`、`turnout`、`platform`、`buffer_stop`、`section_marker`、`text`。
版本高于程序支持时会给出提示而不是静默打开。

## 自动恢复

- 有未保存改动时，程序每 60 秒（可在属性面板调整，最短 15 秒）把快照写入
  `%TEMP%\RailLayout\autosave\<会话>.autosave.rld`，并在同目录维护 `recovery.json` 索引。
- 每个标签页各自一份快照（按会话 ID 区分），互不影响。
- 保存成功、关闭该标签页或正常退出后，对应的快照会被清理。
- 若上次是异常退出（崩溃/强杀），启动时会**逐份**询问「恢复工程 / 丢弃快照」；丢弃需要二次确认。
- 原文件比快照更新时不会提示恢复（视为旧快照）。

## 单位与纸张

- 画布单位：1 单位 = 96dpi 像素 ≈ 0.2646 mm；A3 横向参考框为 1587×1123 单位。
- 纸张边框参考线只作参考（虚线绘于内容下方），导出 PDF 时不打印。
- 导出为矢量 PDF（300 dpi 设备精度），可选「整张图 / 当前视图」、A4/A3/A2/自定义、边距、以及
  「自动适配纸张」或「100% 原始尺寸」。导出时会自动隐藏网格、纸张参考线与选中状态。

## 已知限制（v1）

- 图元之间不做拓扑联动：拖动道岔不会自动带动相连线段（可用框选多选后整体拖动，再吸附微调）。
- 联络线只负责「连起来」：不会自动在接点处生成道岔，也不会改动被跨股道。
- 不含信号机、绝缘节、水鹤等符号（可通过「文字标注」临时替代）。
- PDF 为单页输出；超出纸张时按设定裁切或缩放到适配。
